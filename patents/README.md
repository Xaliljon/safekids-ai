# patents/

Intellectual property workspace: invention disclosures, prior-art searches,
and patent application drafts.

## Rules

- **Confidential.** Contents here may be more sensitive than code — check with counsel before moving this material to any public or shared location.
- One folder per invention disclosure: `NNNN-short-title/` containing the disclosure, prior-art notes, and drawings.
- Disclose **before** publishing: papers, blog posts, or public repos describing an invention can destroy patentability in many jurisdictions.
- Core IP remains proprietary; selected components may be open-sourced deliberately (docs/01, open innovation) — that decision goes through an ADR.
