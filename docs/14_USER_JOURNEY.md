# Purpose

This document describes how each user interacts with Guardian AI throughout a normal working day.

The objective is to understand:

- User activities
- User emotions
- User decisions
- AI involvement
- Pain points
- Opportunities for improvement

The User Journey will guide:

- Product Design
- Mobile Application
- Dashboard
- Notification System
- AI Event Pipeline
- PRD

---

# Journey Overview

Guardian AI serves multiple user groups.

Primary journeys:

1. Kindergarten Director

2. Teacher

3. Parent

4. System Administrator

Children are protected users and do not directly interact with the system.

---

# Director Journey

## 07:00

Director arrives.

Opens Guardian AI Dashboard.

Checks:

- Device status
- Camera health
- AI system health
- Overnight alerts

Expected experience:

Everything operational within 30 seconds.

---

## 08:00

Children begin arriving.

AI automatically detects:

- Active classrooms
- Camera connectivity
- AI readiness

Director does not need to manually monitor cameras.

---

## 09:30

Normal operation.

Director performs administrative work.

Guardian AI continuously monitors classrooms in the background.

No interruptions unless important events occur.

---

## Example Event

10:18

AI detects:

Possible Child Fall

Confidence:

96%

Director receives notification.

Notification contains:

- Classroom
- Timestamp
- Event type
- Confidence score
- Short video clip

Director reviews the event.

Decision:

✓ Confirm

or

✓ Dismiss

Human review is always required.

---

## Afternoon

Guardian AI continues monitoring.

Dashboard displays:

- Event history
- Camera health
- Device health
- Alert statistics

---

## End of Day

Director reviews:

- Daily summary
- Event statistics
- Device status
- AI performance

No manual video review required unless necessary.

---

# Teacher Journey

Teacher starts class.

Guardian AI operates silently.

Teacher focuses on children.

AI does not interrupt normal teaching.

If an important event occurs:

Teacher is informed through the director or local notification (future feature).

Guardian AI never evaluates teacher performance.

Its purpose is assistance.

---

# Parent Journey

Version 1

Parents do not directly interact with Guardian AI.

Their experience is indirect.

Parents benefit through:

- Faster response
- Improved safety
- Better trust

Future versions may include:

- Safety reports
- Transparency features
- Incident notifications approved by kindergarten

Parents never receive unrestricted camera access.
