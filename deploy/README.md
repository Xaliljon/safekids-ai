# Guardian Edge — Deployment & Release

Everything needed to put a Guardian Edge Box into a real kindergarten and
keep it running without a developer. Operator-facing instructions live in
[PILOT_GUIDE.md](../PILOT_GUIDE.md); this directory is the packaging.

| File | Purpose |
| --- | --- |
| `install.sh` | One-command installer (toolchain, deps, validation, model, systemd) |
| `guardian-edge.service` | systemd unit — process-level auto-recovery |
| `RELEASE_NOTES.md` | What each release contains and why |
| `build-info.json` | Build metadata — generated by `make release` |
| `requirements-lock.txt` | Exact dependency manifest — generated by `make release` |

## System requirements

| Requirement | Minimum | Recommended |
| --- | --- | --- |
| Device | Intel N100 class | NVIDIA Jetson (JetPack 6) |
| Python | 3.10 | 3.12 |
| RAM | 2 GB free | 8 GB |
| Disk | 5 GB free | 32 GB |
| Network | LAN with the cameras and guardian phones | Wired Ethernet |
| Cameras | Any RTSP (H.264) camera | ONVIF-capable (enables discovery) |

No internet access is required at runtime — the box works fully offline.
Internet is needed once, at install time, to fetch dependencies and the model.

## Install

```bash
git clone <release-tag> guardian-ai && cd guardian-ai
GUARDIAN_HOME=~/guardian ./deploy/install.sh
```

The installer validates the environment (Python, dependencies, disk, RAM,
network, permissions) and **refuses to proceed** on failure. Every run writes
`$GUARDIAN_HOME/reports/install-report.json`.

Then: `guardianctl wizard` → `guardianctl diagnose` → `systemctl start guardian-edge`.

## Release packaging

```bash
make release VERSION=0.2.0
```

produces `dist/`: the `guardian-edge` wheel, `build-info.json` (version, git
commit, build time, host), and `requirements-lock.txt` (the exact dependency
set the release was tested against).

## Rollback

Releases are git tags; configuration is forward/backward compatible within a
minor version.

```bash
guardianctl backup                      # 1. keep the current configuration
sudo systemctl stop guardian-edge      # 2. stop the box
git checkout <previous-release-tag>    # 3. return to the previous release
./deploy/install.sh                    # 4. reinstall (idempotent)
guardianctl restore <backup.zip>       # 5. bring the configuration back
sudo systemctl start guardian-edge    # 6. restart and verify
guardianctl health
```

The backup archive contains configuration only (cameras, trusted devices) —
never models, video, images, or logs — so it is small and privacy-safe by
construction.
